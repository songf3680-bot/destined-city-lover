# 《测测你的宿命恋人在哪个城市》

基于中国地理风物气质打造的趣味人格测试网页，纯前端静态实现，无需后端即可直接运行。

## 功能亮点
- **40 道生活化单选题**：围绕日常习惯、处事方式、社交模式、情绪反应与兴趣偏好五大篇章展开，轻松好玩，非历史/地理考试或心理诊断。
- **六维标准化评分算法**：从「烟火松弛、诗意清雅、炽热直球、旷达山野、摩登锋芒、厚重笃定」六个维度动态标准化，精准匹配覆盖全国七大地理区划的 **16 座中国城市**（成都、重庆、大理、苏州、杭州、上海、北京、青岛、西安、乌鲁木齐、哈尔滨、武汉、长沙、广州、深圳、厦门）。
- **国风视觉与分享体验**：宣纸米白与松烟墨韵配色、六维雷达图对比、匹配的性格特点、匹配理由、隐藏优势、趣味彩蛋、专属记忆点文案，支持一键生成 **3:4 高清小红书/朋友圈分享海报 PNG** 与一键复制分享文案。
- **全端适配**：响应式布局适配手机、平板与电脑，支持自动断点续答与键盘 `1–4` / `A–D` 快捷作答。

## 运行方式
解压后直接双击打开 `index.html` 即可在浏览器中完整运行，无需安装任何依赖或启动后端服务。

## 文件清单
- `index.html`：主页面结构
- `styles.css`：国风视觉样式与响应式布局
- `data.js`：40道题目与16座中国城市完整数据配置
- `app.js`：答题交互、六维评分、SVG雷达图与纯Canvas海报生成引擎
